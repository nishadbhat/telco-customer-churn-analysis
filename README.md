# telco-customer-churn-analysis
Customer churn analysis with SQL data transformation and Tableau dashboards to uncover churn patterns and support retention decision-making.

This project analyzes customer churn patterns within a telecommunications dataset to identify high-risk segments and revenue exposure across contract types and tenure groups

Key Analytical Areas

1. Customer Churn by Contract Type
Evaluated churn distribution across Month-to-Month, One-Year, and Two-Year contracts to identify contract structures with higher attrition risk.

2. Revenue Lost Across Contract Type
Quantified total revenue lost due to churn within each contract category to assess financial impact and prioritize retention efforts.

3. Customer Churn Rate by Tenure Group and Contract Type
Segmented customers into tenure bands to analyze how churn risk evolves over time.

4. Tenure vs Churn Analysis
Examined churn likelihood relative to customer tenure to identify early vulnerability and long-term retention patterns.
